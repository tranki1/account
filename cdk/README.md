# Accounts Service — AWS CDK (C#)

Infrastructure-as-code for the Accounts microservice.

## What it provisions

- **VPC** (2 AZs, 1 NAT gateway)
- **RDS PostgreSQL 16** with credentials generated into **AWS Secrets Manager**
  (secret name `account-service/db-credentials`), encrypted storage, deletion protection
- **ECS Fargate** service behind an Application Load Balancer, image built from the
  repo `Dockerfile`, DB connection string injected from Secrets Manager
- **SSM Parameter Store** entry for the OTLP exporter endpoint
- **AWS AppConfig** application/environment/profile for feature flags

## Region

Defaults to `eu-central-1` (Frankfurt), overridable via `CDK_DEFAULT_REGION`.

## Prerequisites

- .NET 10 SDK
- Node-based AWS CDK CLI: `npm install -g aws-cdk`
- AWS credentials configured for the Mascus account

## Commands

Run from the `cdk/` directory:

```bash
cdk bootstrap          # once per account/region
cdk synth              # synthesize CloudFormation
cdk diff               # preview changes
cdk deploy             # deploy the stack
```

## Notes

- No secrets are stored in code or config; the database password is generated by
  CDK and only ever lives in Secrets Manager.
- The ECS task expects the app to expose `/health` (HTTP 200) for the ALB health check.
